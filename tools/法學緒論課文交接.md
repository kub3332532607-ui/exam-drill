## 已確認的講義過時或錯誤
- 第 1–4 單元：自治條例罰鍰上限 10 萬且「得規定連續處罰」（地制法第 26 條）；判例已廢止（2019）；總統彈劾由憲法法庭審理；通姦罪已因釋字 791 失效；性別工作平等法已改名性別平等工作法；新自然法學派不是實證主義；舊 c7s1 的「工資 2 年」民法第 127 條並無此項，已刪。
- 第 5–7 單元（已在課文修正）：公務員服從義務 111 年改為服務法第 3 條（違法應報告、書面署名下達才服從、違反刑事法律無服從義務），講義寫舊第 2 條；釋字 371／572／590 已由憲法訴訟法第 55 條取代；強制工作已因釋字 812（110/12/10）失效；釋字 275 推定過失已由行政罰法第 7 條取代；怠金用於行為或不行為義務，講義寫「公法上金錢給付義務」是錯的；講義「國民居留外國亦適用我國法律」太寬，刑法第 7 條限最輕本刑 3 年以上且犯罪地也罰；使領館不是擬制領域（刑法第 3 條只擬制船艦航空器）；非常上訴由最高檢察署檢察總長提起（107 年更名）；檢肅流氓條例 98 年廢止；新冠特別條例 112/6/30 期滿；拘留是社維法的處罰，不在行政罰法列舉。
- 已查證：公務員服務法禁止經營商業是現行第 14 條（111 年修正後）。
- 未能查證、正文沒有引用：中標法第 16 條是否有「有利於人民」但書（兩個來源引文都沒有，正文只寫確認過的兩句）；刑法第 90 條是否已由立法院正式刪除（正文只寫釋字 812 宣告失效）。law.moj.gov.tw 擋機器人讀取，查條文可用 6laws.net。

## 建構方式
- data/jur.js 每節一行 JSON，改寫時用 python 讀 JSON 整行替換（不要用 node require 執行資料檔，會被自動審核擋下），並把題目的 sec 改掛新節；以 python 檢查表格欄數、粗體配對再 push。
- con.js 的節也是每節一行（json.dumps 用 ensure_ascii=False、separators=(',',':') 可原樣還原）；每章最後一節那行結尾不是純 JSON，處理時要另外切。
